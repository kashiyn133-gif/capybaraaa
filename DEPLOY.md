# Deploy CapyPlan (free, about 2 minutes)

## Easiest: Netlify Drop
1. Unzip this file so you have the `capyplan` folder.
2. Go to https://app.netlify.com/drop and drag the whole `capyplan` folder onto the page.
3. Netlify gives you a live link. Put it in your Devpost submission.

## GitHub Pages
1. Create a new public repo and upload all files in the folder (keep `index.html` at the top level).
2. Repo Settings > Pages > Deploy from branch > `main` and `/ (root)` > Save.
3. Your link will be `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Install on a phone
Open the live link in Chrome (Android) or Safari (iPhone). Use "Install app" or "Add to Home Screen". It then opens like an app and works offline.

## Test before you submit
Add tasks, Build my plan, run a focus session, press Test Capy call, Load demo history, export the CSV, and try it on your phone. Click the page once before testing sound, because browsers block audio until then.
